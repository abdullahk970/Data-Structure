# 🧠 Data Structures in C — Practice Collection

> A beginner-level collection of C programming exercises focused on arrays, input handling, iteration, functions, and introductory data-handling concepts.

![C](https://img.shields.io/badge/C-Programming-blue)

---

## 📌 Overview

This repository contains small C programs created to practice fundamental programming and data-handling concepts.

The exercises focus on:

- Character input
- Arrays
- Array traversal
- Loops
- Functions
- Basic modular programming

This repository represents an early stage of my programming and problem-solving journey.

---

## ✨ Concepts Covered

### 📥 Character Input

Practice using standard input functions to read and process characters.

### 📊 Array Initialization

Examples covering:

- Static arrays
- Indexed storage
- Loop-based initialization
- Sequential data handling

### 📚 Array Traversal

Examples demonstrating:

- Iterating through array elements
- Function calls
- Basic code decomposition
- Reusable logic
